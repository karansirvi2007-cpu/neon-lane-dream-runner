# Neon Lane Dream Runner

Create a modern, visually stunning 3D mobile and web game called "NEON RUSH".



GAMEPLAY:



- Create an endless runner game where players control a futuristic character running through a neon city.

- Players can swipe left and right to change lanes.

- Swipe up to jump and swipe down to slide.

- Avoid obstacles, collect glowing coins and earn points.

- Increase the game speed gradually as the player progresses.

- Add a restart button and pause button.

- Include a high score system.



GRAPHICS:



- High-quality 3D graphics.

- Beautiful futuristic neon city environment.

- Glowing lights, realistic shadows and smooth animations.

- Attractive character designs.

- Colorful particle effects when collecting coins.

- Smooth camera following the player.

- Professional gaming UI with modern buttons.



FEATURES:



- Main menu with Play button.

- Character selection screen.

- Coin collection system.

- Daily rewards.

- Sound effects and background music.

- Game over screen showing score and best score.

- Responsive design for Android phones and desktop browsers.



IMPORTANT:

Make the game fully playable, not just a visual prototype. Implement actual movement, collision detection, scoring, obstacle spawning and restart functionality.



Use free assets and open-source technologies wherever possible. Optimize performance for budget Android phones. Do not include paid APIs or paid services.
